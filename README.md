#  Music Store Data Analysis using PostgreSQL

## 📌 Project Overview

This project focuses on analyzing a Music Store database using PostgreSQL to extract meaningful business insights.

The database contains information about artists, albums, tracks, genres, customers, employees, invoices and playlists.

The main objective is to use SQL queries to analyze sales performance, customer purchasing behavior, popular music genres and artist performance.

## 🎯 Project Objectives

- Analyze music store sales and revenue.
- Identify the highest-spending customers.
- Find countries and cities generating the highest revenue.
- Identify popular music genres across different countries.
- Analyze artist performance and track popularity.
- Understand customer purchasing patterns.
- Extract meaningful business insights from relational database tables.

## 🗄️ Database Schema

The project uses a relational database consisting of the following tables:

1. Artist
2. Album
3. Track
4. Genre
5. MediaType
6. Playlist
7. PlaylistTrack
8. Customer
9. Employee
10. Invoice
11. InvoiceLine

## 📊 SQL Analysis

The project contains three levels of SQL questions.

### 1. Easy Level

- Identify the senior-most employee.
- Find countries with the highest number of invoices.
- Identify the top three invoice values.
- Find the city generating the highest revenue.
- Identify the customer who spent the most money.

### 2. Moderate Level

- Identify customers who listen to Rock music.
- Find the top 10 Rock music artists based on track count.
- Identify tracks longer than the average song length.

### 3. Advanced Level

- Analyze customer spending on the best-selling artist.
- Find the most popular music genre in each country.
- Identify the highest-spending customer in each country, including ties.
